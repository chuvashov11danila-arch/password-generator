# password-generator
Генератор безопасных паролей

Программа на Python, которая генерирует надежные пароли с настройкой длины и типов символов.

## 🕹️ Возможности
- Генерация заданного количества паролей.
- Настройка длины пароля.
- Выбор типов символов: цифры, прописные и строчные буквы, спецсимволы.
- Исключение неоднозначных символов (например, `l` и `1`, `O` и `0`).
- Защита от неверного ввода (лимиты длины и количества).
